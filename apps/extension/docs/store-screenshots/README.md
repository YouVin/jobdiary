# 최신 개발 버전의 소개 이미지

2026-11-05, GitHub 공개 자료 정리 #133. 이전의 보라색 팝업 이미지를 최신 흑백 일기장 UI로 교체했다.

- 1-overview.png: 지원 기록 수집과 가져오기
- 2-copy.png: 표 복사와 실제 완료 UI
- 3-start.png: 수집 전 상태
- 4-sites.png: 세 사이트의 수집 슬롯
- 5-history.png: 정확한 공고 ID에 대한 실제 지원·취소 배지

각 소개 이미지는 1280×800 PNG다. 실제 팝업/배지 UI를 예시 데이터로 촬영했고 사이트 영역은 안내용 구성이다. 개발 구현 기준이며 웹스토어 게시 자료로 업로드한 상태를 의미하지 않는다.

[제작 도구와 재생성 방법](../../scripts/store-screenshots/README.md) · [GitHub 갱신 기록](../../../../docs/GITHUB_SHOWCASE.md)

raw/capture-manifest.json은 UI 출처·데이터·촬영 상태를, render-manifest.json은 이미지 파일·규격을 기록한다. 실제 계정·지원정보는 포함하지 않는다.
