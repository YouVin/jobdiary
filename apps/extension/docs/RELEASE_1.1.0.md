# 1.1.0 변경 및 검증 기록

2026-11-06 · #135 / #137 / #139. **확장 소스 버전1.1.0을 반영했다.** package.json과 루트 lock의 확장 항목만 갱신했으며 웹앱 버전은0.1.0으로 유지한다. 스토어 업로드·심사·main 배포·공개 정책 게시를 완료한 기록이 아니다.

## 기존 1.0.3 이후 변경

- 모노레포 apps/extension으로 이동하고 앱별 빌드·테스트·버전을 유지한다.
- 확인된 마감일만 수집·정규화·전달하고 출처 없음/조회 실패는 기존 지원내역을 유지한다.
- 웹앱 저장 이력을 기준으로 최소 비교 캐시를 동기화한다. 수집 슬롯과 분리하고 로그아웃·계정 변경 때 정리한다.
- 잡코리아·사람인의 정확한 공고 ID에 지원/취소 이력을 표시한다. 원티드는 공고 식별 정보 부족으로 제외한다.
- 흑백 일기장 팝업·로컬 오늘 날짜·작은 달력, 복사/초기화 버튼과 간결한 설정을 제공한다.
- 중복 배지·오래된 웹앱 탭의 캐시 덮어쓰기·무효 확장 컨텍스트·CRXJS 개발 재연결 문제를 수정했다.
- 배포 ZIP은 실제 Vite outDir를 압축하고 개발 모드로는 생성하지 않는다. CI에서 ZIP/빌드 일치를 검사한다.

새 API/host 권한은 추가하지 않았지만 잡코리아·사람인 자동 표시 스크립트는 기존 허용 호스트의 전체 경로에 주입된다. 이를 개인정보처리방침과 스토어 설명에 반영해야 한다.

## 검증과 남은 범위

익스텐션 221개 테스트, TypeScript·운영/개발 빌드, 개발·운영 Chrome 각각 15개 표본 시나리오, 웹앱 연동 10개와 수집/마감일 8개 시나리오가 통과했다. 운영 ZIP은 30개 파일·104,881바이트이며 운영 출력과 내용이 같았다. 이는 버전 반영 전1.0.3으로 생성한 검증용 산출물이며 업로드에 사용하지 않는다. 최종1.1.0 파일은 아래 기록을 따른다.

사용자가 사람인·잡코리아 로그아웃 뒤에도 라벨이 남는 동작과 원티드 탈락의 웹앱 반영을 확인했다. 채용 사이트 로그인과 표시가 독립적이며 취준일기 웹앱 계정 이력이 기준임을 안내했다. 실계정 모든 템플릿·모바일 날짜·계정 전환과 스토어 ID의 운영 연동은 남아 있다. [전체 출시 점검](../../../docs/EXTENSION_RELEASE_CHECK.md)에 현재 결과와 확인 순서를 기록한다.
