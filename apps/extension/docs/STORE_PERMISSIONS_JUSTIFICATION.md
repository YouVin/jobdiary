## 단일 목적 설명 (Single purpose description)

```
사람인, 잡코리아, 원티드 지원현황 페이지에서 유저가 지원한 내역(회사명,
공고명, 상태, 지원일, 확인 가능한 마감 표시)을 유저의 명시적인 버튼 클릭으로 수집해 브라우저
로컬에 저장하고, 유저가 원할 때 취준일기 웹앱으로 전달한다.
웹앱 기준 최소 이력을 로컬에서 비교해 잡코리아·사람인의 일치 공고에 지원/취소 이력을 표시한다.
마감 표시는 연도까지 확인된 유효 날짜인 경우에만 마감일로 저장·전달한다.
```

## 권한별 사용 이유 (Permission justification)

### `storage`

```
수집한 지원 내역을 유저의 브라우저 로컬 저장소(chrome.storage.local)에
저장하기 위해 필요합니다. 이 정보는 브라우저 밖으로 자동 전송되지 않으며,
유저가 팝업의 "수집 내역 초기화" 버튼을 누르면 수집 슬롯을 지웁니다. 웹앱에서 전달받는 최소
비교 정보(사이트·공고 ID·지원/취소 구분·계정 구분용 해시·갱신 시각)는 별도 로컬 캐시에
저장하며 웹앱 로그아웃/계정 변경 시 정리합니다. 자동 표시 설정도 별도 로컬 키에 저장합니다. 익스텐션 삭제 시 이 정보가 모두 삭제됩니다.
```

### Host permission

실제 manifest 패턴(`manifest.config.ts`의 `host_permissions` 그대로):

```
https://*.saramin.co.kr/*
https://www.jobkorea.co.kr/*
https://jobkorea.co.kr/*
https://www.wanted.co.kr/*
https://wanted.co.kr/*
```

```
유저가 이미 로그인해서 보고 있는 사람인·잡코리아·원티드의 지원현황
페이지에서, 유저가 익스텐션 팝업의 "지원내역 수집하기" 버튼을 직접 눌렀을
때만 화면에 표시된 지원 내역(회사명, 공고명, 상태, 지원일, 마감 표시 등)을 읽기 위해
필요합니다. 사람인은 모바일 지원현황(/apply/state) 한 페이지를 추가 요청해 지원 ID와
공고 ID가 모두 일치하는 마감일만 보충합니다. 쿠키·토큰 값을 코드로 읽거나 저장하지
않지만 요청에는 브라우저가 허용하는 기존 로그인 상태가 사용될 수 있습니다.

위 host_permissions의 범위 안에서 수집 스크립트는 기존 지원현황 경로에만 주입합니다.
별도 표시 스크립트는 HTTPS www.jobkorea.co.kr·jobkorea.co.kr 및
www.saramin.co.kr·saramin.co.kr·m.saramin.co.kr 전체 경로의 최상위 문서에 주입합니다.
페이지의 공고 링크 URL·텍스트 존재 여부·단일 상세 제목을 기존 비교 캐시와 대조하며
방문 목록이나 페이지 원문을 저장하지 않고 공고별 네트워크 요청도 보내지 않습니다.
기본 활성인 자동 표시는 팝업에서 끌 수 있으며 숨겨진 탭은 작업·저장소 구독·공고 Map을 해제합니다.
원티드는 표시 기능 대상에서 제외하며 새로운 host/API 권한을 추가하지 않습니다.
모바일 지원현황 보충 요청과 모바일 공고 표시 주입은 별개 기능입니다.
보충 실패 시 기존 PC 수집 결과를 유지하며 모바일 HTML은 저장·로그·웹앱 전달하지 않습니다.
잡코리아는 수집된 지원의 /Recruit/GI_Read/{공고ID} 공개 상세만 쿠키 없이 조회합니다.
최대 10개·동시 2건·요청당 4초이며 ID/표시 날짜/구조화 날짜가 일치할 때만 보충합니다.
상시채용·날짜 불명확·조회 실패 시 날짜를 생략하고 지원내역은 유지합니다.
공고 원문은 저장하지 않으며 이 마감일 보충을 위해 권한을 확대하지 않습니다.
표시 결과의 배지는 페이지 DOM에서 관찰할 수 있으나 원본 비교 캐시·계정 해시는 넣지 않습니다.
```

### Remote code

```
이 익스텐션은 원격 코드를 실행하지 않습니다. 모든 로직은 익스텐션 패키지에
포함된 코드로만 동작합니다.
```
