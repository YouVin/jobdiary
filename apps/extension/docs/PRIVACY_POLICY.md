# 개인정보처리방침

**시행일: 2026-10-22**

취준일기 익스텐션("이 익스텐션")은 사람인·원티드·잡코리아 지원현황 페이지에서
유저가 버튼을 눌렀을 때 지원 내역을 읽어와 취준일기 웹앱으로 전달하는 걸 돕는
크롬 확장 프로그램이다. 이 문서는 이 익스텐션이 어떤 정보를 어떻게 다루는지
설명한다.

## 1. 핵심 원칙

이 익스텐션은 **유저의 로그인 정보(아이디, 비밀번호, 쿠키, 인증 토큰 등)를
수집하거나 저장하지 않는다.** 유저가 이미 로그인해서 브라우저에 띄워놓은
지원현황의 텍스트를 읽는다. 사람인은 같은 사용자의 모바일 지원현황도
요청해 확인 가능한 마감일을 보충할 수 있다.
잡코리아는 지원한 공고와 연결된 공개 상세 페이지의 마감일 메타 정보를 확인할 수 있다.

## 2. 수집하는 정보

유저가 지원현황 페이지에서 익스텐션 팝업의 "지원내역 수집하기" 버튼을 눌렀을
때만, 해당 지원현황·사람인 모바일 지원현황·연결된 잡코리아 공개 공고에서 다음 정보를 읽는다:

- 회사명, 공고명(포지션)
- 지원 상태(예: 지원완료, 불합격, 지원취소 등) 원문
- 지원일
- 공고 마감 표시(사이트가 제공하는 경우). 연도까지 확인된 유효 날짜만 마감일로 저장·전달하며, 연도 없는 표시나 상시채용은 생략한다.
- 공고 고유 ID(사이트가 제공하는 경우) — 중복 지원 판별용
- 열람 여부(사이트가 제공하는 경우)
- 공고 페이지 URL(사이트가 제공하는 경우)

이 정보는 모두 유저 본인이 사이트에 지원한 이력이며, 익스텐션은 이 외의
정보(계정 정보, 이력서 내용, 다른 유저의 정보 등)를 읽거나 수집하지 않는다.

## 3. 정보 수집 방식

- **유저가 명시적으로 버튼을 눌렀을 때만** 수집한다. 정기적인 자동 수집은 하지 않는다.
- 쿠키나 인증 토큰의 값을 코드로 읽거나 저장하지 않는다. 지원현황 페이지를 요청할 때
  브라우저가 허용하는 기존 로그인 상태가 사용될 수 있으며 재로그인이나 인증 우회를 수행하지 않는다.
- 사람인·잡코리아는 페이지 번호를 바꿔가며 같은 방식으로 여러 페이지를
  추가로 불러올 수 있지만, 이는 유저가 이미 로그인해서 볼 수 있는 같은
  지원현황 목록의 다른 페이지일 뿐 새로운 권한이나 세션을 사용하지 않는다.
  원티드는 화면의 실제 "다음 페이지" 버튼을 클릭하는 방식으로 페이지를
  넘긴다.
- 사람인은 PC 수집 후 `https://m.saramin.co.kr/apply/state`의 모바일 지원현황 한 페이지를
  추가 요청할 수 있다. 지원 ID와 공고 ID가 모두 일치할 때만 제목에 표시된 연도 포함
  마감일을 보충한다. 추천공고, 이력서, 메시지, 인증 정보는 수집 항목으로 저장하지 않는다.
  모바일 원문 HTML도 저장하거나 웹앱에 전달하지 않는다. 조회 실패 시 PC 수집 결과를 유지한다.
- 잡코리아는 지원한 공고 링크에 해당하는 공개 상세 페이지를 최대 10개, 동시 2건까지
  추가 요청할 수 있다. 이 요청에는 로그인 쿠키를 보내지 않는다. 공고 ID 및 표시용
  마감일과 구조화 날짜가 일치할 때만 날짜를 보충하고 상시채용은 제외한다.
  조회 실패 시 기존 내역을 유지하며 공고 원문 HTML은 저장·로그·웹앱 전달하지 않는다.

## 4. 정보 저장 위치와 보관 기간

- 수집한 정보는 **유저의 브라우저 안(`chrome.storage.local`)에만** 저장된다.
  이 익스텐션을 운영하는 서버는 없으며, 수집한 정보가 개발자나 제3자에게
  자동으로 전송되지 않는다.
- 사이트별로 슬롯을 나눠 누적 저장하며, 같은 사이트를 다시 수집하면 그
  슬롯만 최신 결과로 덮어쓴다.
- 유저가 팝업의 "초기화" 버튼을 누르면 수집 슬롯의 지원내역이 삭제된다.
  아래 비교 캐시는 별도로 유지하며, 익스텐션을 삭제하면 두 종류의 저장 정보가 함께 삭제된다.

## 5. 정보를 내보내는 방법 (유저가 직접 트리거하는 경우만)

익스텐션은 정보를 서버로 자동 전송하지 않는다. 정보가 브라우저 밖으로 나가는
경우는 다음 두 가지뿐이며, 둘 다 유저의 명시적인 클릭으로만 일어난다.

- **클립보드 복사**: 팝업의 "전체 복사" 버튼을 누르면 저장된 정보를 클립보드에
  복사한다. 이후 유저가 어디에 붙여넣을지는 유저가 결정한다.
- **취준일기 웹앱 연동**: 팝업의 "취준일기 열기" 버튼을 누르면 취준일기 웹앱
  (`jobdiary.vercel.app`)을 새 탭으로 열면서 가져오기 신호를 함께 보낸다. 그
  신호를 받은 웹앱이 익스텐션에 저장된 정보를 요청하고, 익스텐션은 그 요청에
  응답해 정보를 전달한다. 이 통신은 취준일기 웹앱에서만 가능하도록 제한돼
  있으며(다른 웹사이트는 이 요청을 보낼 수 없음), 유저가 "취준일기 열기"를
  직접 누르지 않는 한 일어나지 않는다.

## 6. 요청하는 권한과 사용 이유

| 권한 | 사용 이유 |
|------|-----------|
| `storage` | 수집한 지원 내역을 유저의 브라우저 로컬 저장소에 저장하기 위함 |
| `host_permissions`(사람인/잡코리아/원티드 도메인) | 지원현황을 읽고 사람인 모바일 지원현황·연결된 잡코리아 공개 공고에서 마감일을 보충하기 위함. 쿠키·토큰 값을 코드로 읽거나 저장하지 않는다 |

`host_permissions`는 크롬 권한 체계상 **각 사이트의 오리진(도메인) 전체**
단위로 부여된다 — 스킴+호스트 단위라 경로(path)까지 세밀하게 제한하는
문법은 없다. 하지만 이 익스텐션이 실제로 코드를 실행하고 정보를 읽는
범위는 그보다 훨씬 좁다: 콘텐츠 스크립트는 각 사이트의 **지원현황 페이지
경로에만** 삽입되며(예: 사람인은
`/zf_user/persons/apply-status-list*`), 팝업이 수집 버튼을 활성화하는
것도 같은 경로 판정을 다시 거친다. 즉 권한이 부여된 범위와 실제로
데이터를 읽는 범위는 다르며, 후자가 훨씬 제한적이다. 마감일 보충 요청은
service worker에서 고정된 사람인 모바일 지원현황 주소로만 보내며 모바일 페이지에
콘텐츠 스크립트를 추가 주입하지 않는다.

이 익스텐션은 위 목적 외의 다른 권한을 요청하지 않는다.

## 7. 제3자 제공

이 익스텐션은 광고, 분석(analytics), 트래킹 SDK를 포함하지 않으며, 수집한
정보를 제3자에게 판매하거나 제공하지 않는다.

## 8. 아동의 개인정보

이 익스텐션은 특정 연령층을 대상으로 하지 않으며, 아동으로부터 개인정보를
의도적으로 수집하지 않는다.

## 취준일기 웹앱의 지원 이력 비교 정보

익스텐션이 설치된 브라우저에서 취준일기 웹앱을 이용하면, 웹앱에 저장한 지원 이력 중
확인 가능한 사이트·공고 ID·지원 이력 또는 취소 구분과 미식별 건수, 계정 구분용 해시가
익스텐션의 브라우저 로컬 저장소에 전달·갱신될 수 있다. 마지막 갱신 시각도 보관한다.
이 해시는 웹앱 사용자 식별자를 단방향 변환한 값이며 인증 토큰이나 비밀번호가 아니다.
회사명·공고명·이메일·원본 사용자 식별자·지원일·마감일·메모·일기는 이 비교 정보에 포함하지 않는다.

비교 정보는 수집 슬롯과 별도로 보관하며 웹앱의 조회와 변경 결과를 기준으로 갱신한다.
웹앱에서 로그아웃하거나 계정을 변경하면 같은 브라우저의 해당 웹앱 비교 정보를 정리한다.
웹앱을 닫은 동안 다른 기기의 변경을 즉시 알 수는 없다. 수집 내역 초기화는 비교 정보를 지우지 않는다.
비교 정보는 채용 사이트나 다른 외부 서버에 전송하지 않는다.
