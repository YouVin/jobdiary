# 1.2.0 변경 및 검증 기록

2026-11-25 · #253. 확장 소스 버전 1.2.0을 반영했다. `package.json`과 루트 lock의 확장 항목만 갱신했고 웹앱 버전은 그대로다. 웹앱은 같은 날 운영 배포(PR #252)로 이 버전의 기능을 이미 제공한다. 스토어 업로드·심사 제출은 사용자가 한다.

## 1.1.0 이후 변경

- **공고 페이지 읽기(#238, 결정 기록 003):** 취준일기 웹앱이 "공고 페이지에서 가져오기"로 요청하면, 지원에 저장된 잡코리아·사람인·원티드 공고의 공개 페이지를 쿠키 없이 읽어 제목·회사명·근무지·근무 일정·본문 글·본문 이미지 주소를 돌려준다. 익스텐션에 저장하지 않는다. 웹앱 origin만 요청할 수 있고 최상위 프레임만 받는다.
- **팝업 디자인 시스템(#239):** 웹앱 토큰(`tailwind.config.ts`)을 그대로 쓰는 회색 바탕·흰 카드·파랑 하나 팝업, 사이트 아이콘, 새 로고 아이콘(16·32·48·128px, 32px 추가).
- **지원 이력 배지(#246):** 지원 이력은 주요 파랑 바탕(5.56:1), 지원취소는 옅은 회색(5.54:1), 모서리 8px. 팝업 설정을 펼치면 사이트별 줄도 접어 600px 안(672 → 560px).

권한은 바꾸지 않았다(`storage` + 기존 채용 사이트 host 5개). 공고 페이지 읽기는 기존 host 권한 안에서 백그라운드가 요청한다.

## 공개 문서

- 개인정보처리방침: 시행일 2026-11-25, 공고 페이지 읽기(요청 조건·읽는 항목·쿠키 없음·저장 없음)와 권한 사용 이유 추가.
- 스토어 설명(`STORE_LISTING.md`): 공고 페이지 읽기 기능과 개인정보 안내. 예전 문장 "공고별 추가 요청도 보내지 않아요"는 자동 표시에 한정되도록 고쳤다.
- 권한 설명(`STORE_PERMISSIONS_JUSTIFICATION.md`): 단일 목적·host 권한 사용 이유·데이터 사용 공개 표에 공고 페이지 읽기 추가.
- 사용 안내(`index.md`): 1.2.0 안내와 "웹앱의 회사 정보와 공고 페이지 읽기" 절.
- 공개 페이지(`youvin.github.io/jobdiary-extension/`, `/privacy/`)는 예전 저장소 `YouVin/jobdiary-extension`의 `dev/docs`에 같은 내용을 반영해 게시한다(기존 절차, `docs/PRODUCTION_RELEASE_2026-11-06.md`).
