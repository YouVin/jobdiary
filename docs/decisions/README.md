# 결정 기록 (Decision Records)

기능·기술을 고를 때마다 같은 틀로 남긴다(#224). 목적은 두 가지다.

1. 왜 그렇게 했는지 나중에 본인 말로 설명할 수 있게 한다(면접·포트폴리오 근거).
2. 고르기 전과 후의 숫자를 남겨, 결정이 맞았는지 확인한다.

## 쓰는 방법

1. [TEMPLATE.md](TEMPLATE.md)를 복사해 `NNN-짧은-이름.md`로 만든다.
2. 문제 → 지금 숫자 → 선택지 → **결정(본인이 직접)** → 성공 기준 → 결과 → 회고 순서로 채운다.
3. AI의 추천을 받았다면 "AI 추천"과 "내 결정"을 나눠 적고, 8절에 내가 한 것과 AI가 한 것을 구분한다.
4. 구현 PR 본문에 결정 기록 번호를 적고, 구현이 끝나면 6·7절을 채워 상태를 "구현 완료"로 바꾼다.
5. 나중에 결정을 바꾸면 기존 기록은 지우지 않고 상태를 "대체됨(→ NNN)"으로 바꾼다.
