## 1. 문제

- 서류에 통과하면 면접 준비를 해야 하는데, 공고가 원하는 인재상과 회사 정보가 공고·홈페이지·공시 자료에 흩어져 있다.
- 공고의 인재상 문장("팀원들과 원활하게 소통하며…")을 **내가 준비해야 할 강점(협업 등)**으로 바꿔 읽는 일은 매번 손이 많이 가고 사람마다 기준이 다르다.
- 작은 회사는 DART 공시에 없어서 회사 정보 자체를 찾기 어렵다.
- 그래서 서류 통과 시점에 "회사 한눈에 + 공고가 원하는 강점 + 기술 요구"를 자동으로 정리해 주려 한다. 이 정리를 맡을 AI 모델을 골라야 한다.

## 2. 지금 숫자

모두 2026-11-24 각 회사 공식 요금표 기준이다. 분석량은 **추정**이며, 평가 단계에서 응답의 실제 사용량(`usage`)으로 다시 잰다.

| 지표 | 값 | 잰 방법·근거 |
|---|---|---|
| 분석 1번 입력 | 약 1만 토큰 (추정) | 지시문·강점 목록 1,500 + 공고 본문 3,000~4,000 + 회사 정리값 1,000 + 홈페이지 5,000 |
| 분석 1번 출력 | 약 3,000 토큰 (추정) | 결과 JSON + 생각 과정 |
| 예상 사용량 | 월 500건 (가정) | 사용자 100명 × 서류 통과 월 5번 |
| 회사 정보 출처 비용 | 0원 | 공고 기업정보(익스텐션), 국민연금 사업장 데이터, DART 모두 무료 |
| 웹 검색 1번 | $0.01 (Claude·OpenAI) | 1,000번에 $10. Gemini는 유료 등급 월 5,000번 무료 후 1,000번에 $14 |

## 3. 선택지

| | A. Claude Haiku 5.5 | B. Gemini 3.5 Flash-Lite | C. OpenAI gpt-5-mini | D. OpenAI gpt-5-nano |
|---|---|---|---|---|
| 요금 (100만 토큰당 입력/출력) | $0.10 / $0.50 | $0.30 / $2.50 | $0.25 / $2.00 | $0.05 / $0.40 |
| 분석 1번 (검색 없이, 추정) | 약 $0.002 (3원) | 약 $0.007 (10원) | 약 $0.006 (8원) | 약 $0.001 (2원) |
| 무료 사용 | 가입 시 소량 크레딧(금액 비공개) | **계속 무료인 등급 있음** (한도 비공개, 커뮤니티 측정 하루 약 500번) | 텍스트 모델 무료 등급 없음 | 없음 |
| 데이터 학습 | 유료 API는 학습에 안 씀 | **무료 등급은 제품 개선에 씀** (유료는 안 씀) | — | — |
| 홈페이지 읽기 | 웹 가져오기 도구 추가 요금 없음(토큰만) | 확인 안 함 | 확인 안 함 | 확인 안 함 |
| 걱정되는 점 | 무료 등급이 없어 카드 등록 필요 | 무료 한도가 자주 바뀌고 문서에 숫자가 없음, 이력서 기능엔 못 씀 | 출력 단가가 A의 4배 | 너무 작아 한국어 강점 연결 품질이 걱정 |

## 4. 결정

> 아래 "AI 추천"은 조사한 AI(Claude)의 의견이다. Claude가 자기 회사 모델을 추천하는 구조라 치우칠 수 있어, 평가 결과를 보고 **본인이 "내 결정"을 직접 쓴다.**

**AI 추천 (초안):** A. Claude Haiku 5.5로 시작하고, 평가에서 품질이 모자라면 Sonnet 5.5로 올린다.
- 단가가 가장 낮은 축이고(D 제외), 홈페이지 읽기에 추가 요금이 없어 비싼 웹 검색을 줄일 수 있다.
- 유료 API라 데이터가 학습에 쓰이지 않아, 나중에 이력서 기능까지 같은 구조로 갈 수 있다.
- 한 업체 안에서 모델 이름만 바꿔 올리고 내릴 수 있다.
- 버린 이유: B는 무료라 매력적이지만 한도와 학습 사용이 걸리고, C는 출력 단가가 높고, D는 품질이 걱정된다.

## 5. 성공 기준과 검증 방법

실제 프론트엔드 공고 10개로 A, Sonnet 5.5, Opus 5.5(필요하면 B도)를 같은 지시문으로 돌려 비교한다.

- **근거 인용 정확도:** 강점마다 붙인 공고 원문 인용이 공고에 그대로 있는 비율 **100%** (코드로 자동 검사)
- **강점 연결이 맞는지:** 본인이 보고 "맞다"고 한 비율 **80% 이상**, Opus 5.5와의 차이 10%p 이내
- **결과 형식 오류:** **0건**
- **비용:** 실측 1건당 $0.01 이하 (웹 검색 제외)
- **응답 시간:** 1건 30초 이내 (서류 통과 알림까지 기다릴 수 있는 시간)
- 평가 비용 예상: $3~5
