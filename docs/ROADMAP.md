# 로드맵

## 개발 순서

웹앱(그릇)을 먼저 만들고, 익스텐션(담는 도구)을 나중에 붙인다.

---

## 1단계 — 웹앱 대시보드 (현재)

**목표**: localStorage 기반으로 직접 입력 + 관리가 되는 MVP

- [ ] 타입 정의 (`types/application.ts`)
- [ ] Zustand 스토어 + localStorage 연동
- [ ] 칸반 보드 UI (5개 컬럼)
- [ ] 지원 카드 컴포넌트
- [ ] 카드 추가/수정/삭제
- [ ] 드래그로 상태 변경 (dnd-kit)
- [ ] 일기 기능 (카드별 일기 작성)
- [ ] 통계 요약 (총 지원/합격률)
- [ ] 텍스트 복사 기능
- [ ] 이미지 카드 공유
- [ ] 반응형 (모바일)
- [ ] Vercel 배포

## 2단계 — 크롬 익스텐션

**목표**: 사람인부터 지원 내역 자동 수집

- [ ] `jobdiary-extension` 레포에 CRXJS 세팅
- [ ] manifest.json 작성
- [ ] 사람인 content script (셀렉터 찾기 → 수집)
- [ ] service worker (저장 로직)
- [ ] popup UI
- [ ] 원티드, 잡코리아 확장
- [ ] 로컬 테스트

## 3단계 — 연동

**목표**: 익스텐션이 수집한 데이터를 웹앱에 자동 반영

- [ ] 익스텐션 → 웹앱 데이터 전달
- [ ] 중복 처리
- [ ] 크롬 웹스토어 배포

## 4단계 — 로그인 + 동기화

**목표**: 여러 기기 동기화. `localStorage` → Supabase로 전환한다 (마이그레이션 없이 로그인하면 새로 시작하는 깨끗한 전환).

자세한 설계는 [SUPABASE.md](./SUPABASE.md) 참고.

- [ ] S-1. Supabase 프로젝트 세팅 + `applications` 테이블 생성
- [ ] S-2. 웹앱-Supabase 연결 (`@supabase/supabase-js`, 환경변수)
- [ ] S-3. 이메일+비밀번호 인증 (회원가입/로그인 UI + 세션)
- [ ] S-4. 저장 로직 전환 (`storage.ts` / `applicationStore` → Supabase)
- [ ] S-5. RLS 적용
- [ ] (이후) 소셜 로그인(구글/카카오) 추가
- [ ] (이후) 익스텐션 → 웹앱 데이터 전달 방식 연동
- [ ] (이후) 중복 감지 결과 표시 UI
