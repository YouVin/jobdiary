# GitHub 소개·스크린샷 갱신 기록

2026-11-05 · [이슈 #133](https://github.com/YouVin/jobdiary/issues/133). 팝업 사용성 개선 [PR #132](https://github.com/YouVin/jobdiary/pull/132)을 dev에 통합한 뒤, GitHub에서 프로젝트를 이해할 수 있도록 소개와 시각 자료를 갱신했다.

## 갱신한 범위

| 위치 | 변경 |
| --- | --- |
| 루트 README | 제품 목적·실제 기능·화면·모노레포 구조·책임 경계·실행·기술 결정과 검증 근거 |
| 확장 README | 최신 버튼명·수집/표시 지원 범위·사용법·저장 경계·현재 이미지 |
| 웹앱 README | 현재 기능과 계획 분리·가져오기와 최종 이력 책임·루트 실행 방법 |
| docs/store-screenshots | 흑백 소개 5장·원본 UI·촬영/렌더 manifest |
| docs/usage-guides | 사이트별 안내 도식 3장, 실제 로그인 화면으로 오인하지 않게 명시 |
| scripts/store-screenshots | 모노레포 경로·별도 Playwright 도구·실제 확장 캡처·규격/링크 확인 |

이미지 경로는 확장 폴더 기준이다. 제품 UI·수집 파서·상태 매핑·권한·웹앱 데이터베이스는 이번에 변경하지 않았다. 공개 Pages·웹스토어 업로드와 main 배포도 수행하지 않았다.

## 정확하게 정리한 설명

- 수집은 사람인·잡코리아·원티드, 자동 표시는 잡코리아·사람인의 정확한 공고 ID 기준으로 구분했다. 일치하지 않는 공고를 미지원으로 단정하지 않는다.
- content script가 수집 결과를 변환해 로컬 슬롯에 저장한다. 기존 소개의 ‘백그라운드가 상태 변환·저장’ 도식을 현재 책임에 맞췄다.
- 웹앱이 최종 지원 이력과 가져오기 중복 판별을 담당하고, 표시용 최소 캐시는 별도로 동기화한다.
- 일기·통계·이미지 공유 UI는 구현된 것처럼 소개하지 않는다. 최신 dev UI와 스토어 반영을 구분했다.
- 근거 없이 붙어 있던 MIT 배지는 제거했다. 이번 작업에서 새 라이선스 조건을 정하거나 라이선스 파일을 추가하지 않았다.

## 이미지의 출처와 재현

UI 기준 커밋은 e683e013b0f1a7d2862af680f3d4178bb261fb32(PR #132 dev 통합)이다. 실제 확장을 별도 정적 development 빌드로 생성하고 독립 Chrome 프로필·예시 저장소로 촬영했다. 사용자 Chrome 프로필이나 실계정은 사용하지 않았다.

수집 슬롯 15건(사람인 5·잡코리아 7·원티드 3)과 표시용 비교 공고 12건·미확인 3건을 사용했다. 일치한 지원·취소 배지는 실제 엔진이 예시 사이트 DOM에 삽입하도록 했고 2개 배지를 확인했다.

클립보드는 운영체제의 개인 내용을 읽거나 덮어쓰지 않도록 촬영 프로필 안에서 어댑터만 모의 처리했다. 실제 복사 핸들러가 만든 15행 TSV·HTML 표와 완료 표시를 확인했다. 완료 문구가 촬영 중 사라지지 않게 그 프로필에서만 복귀 타이머를 늦췄다. 제품 타이머나 실제 외부 문서 앱의 붙여넣기 동작을 바꾼 것은 아니다.

소개 5장은 1280×800, 사이트 안내 3장은 1120×760이다. 실제 UI 원본은 360px·2배 밀도로 촬영하며 기본 539.5px와 설정 펼침 583px에서 잘림·내부 스크롤이 없었다. 배지 예시 사이트는 680×460이다. 모든 그림 안에 개발 화면·예시 데이터 또는 안내 도식임을 표시했다.

[제작 명령](../apps/extension/scripts/store-screenshots/README.md)으로 capture → compose → check를 실행할 수 있다. 촬영 시각·소스 커밋·상태별 크기는 [촬영 manifest](../apps/extension/docs/store-screenshots/raw/capture-manifest.json), 최종 파일·규격은 [렌더 manifest](../apps/extension/docs/store-screenshots/render-manifest.json)에 남긴다.

## GitHub About에 적용할 문구

현재 연결 도구는 저장소 About 편집을 지원하지 않고, 대체 CLI도 인증되어 있지 않아 실제 About은 변경하지 못했다. README와 이미지·이슈/PR 갱신은 연결 도구와 Git으로 수행한다. 아래 문구는 저장소 About의 편집 버튼에서 그대로 적용할 수 있다.

**Description**

> 사람인·잡코리아·원티드 지원내역을 모으는 Chrome 확장과 지원 현황을 관리하는 웹앱 · npm workspaces 모노레포

**Website**: https://jobdiary.vercel.app (기존 주소 유지)

**Topics**: nextjs, react, typescript, chrome-extension, manifest-v3, monorepo, job-tracker

## 확인 결과와 남은 범위

- 별도 정적 development 빌드 성공, 활성 apps/extension/dist 보존.
- 실제 UI 6개 상태와 실제 엔진의 배지 2개 촬영, 페이지 오류 0개.
- 소개 이미지 5장·안내 도식 3장과 원본 규격·로컬 README 링크 확인.
- UI 소스는 앞선 PR #132의 221개 테스트·Chrome 14개 검증을 유지한다. 문서·촬영 도구만 바꾼 이번 작업에서 전체 앱 테스트를 로컬에서 불필요하게 재실행하지 않았다.
- 실제 로그인 사이트의 최신 화면·외부 문서 앱 붙여넣기·스토어 업로드 결과를 검증한 자료로 표현하지 않는다. 현재 자료의 목적은 GitHub 소개와 개발 구현의 재현 가능한 설명이다.

About의 직접 적용과 공개 사이트/스토어 반영은 남아 있다.
