# 홈 통계 대시보드

관련 이슈: #146~#150. 계산은 `apps/web/src/utils/applicationStats.ts`, 테스트는 `apps/web/tests/applicationStats.test.mjs`.

## 계산 기준 (#146)

- 통계는 검색·필터와 무관하게 항상 전체 지원 내역으로 계산한다.
- 날짜는 화면 표시(`formatDate`)와 같이 저장된 ISO 값의 UTC 날짜를 쓴다. 날짜만 있는 값(`YYYY-MM-DD`)은 그대로 쓰고, 해석할 수 없는 값은 계산에서 뺀다.
- 오늘은 `getTodayInKorea()`의 한국 날짜다. 이번 주는 그 주 월요일부터 오늘까지다.

| 값 | 기준 |
|---|---|
| 전체 지원 | 지원 내역 수 (지원취소 포함) |
| 지원한 기업 | 회사명의 유니코드 NFKC, 공백 제거, 소문자 정규화 후 고유 개수 |
| 진행 중 | 지원완료·서류통과·면접예정·면접완료 |
| 서류 통과 | 서류통과·면접예정·면접완료·합격 (서류 단계를 넘긴 건수) |
| 종료 | 합격·탈락·지원취소 |
| 서류 통과율 | 서류 통과 ÷ (전체 − 지원취소). 분모가 0이면 표시하지 않는다 |
| 마감 자동 탈락 | 탈락이면서 `statusSource`가 `deadline`인 건수 |
| 지원 경로 | 플랫폼별 건수·비율. 건수순, 같으면 사람인·잡코리아·원티드·직접입력 순. 0건도 포함 |
| 다가오는 일정 | 종료되지 않은 지원의 면접일·공고 마감일 중 오늘 이후. 날짜순, 같은 날이면 면접 먼저 |
| 최근 지원 | 지원일 최신순, 같은 날이면 최근 수정순 |

지원취소는 사용자가 지원을 거둔 경우라 전형 결과가 아니다. 그래서 전체 수에는 넣고 통과율 분모에서는 뺀다.

## 화면 구성 (#147)

- 홈(`/`)은 통계 대시보드, 지원 보드(`/board`)는 기존 검색·필터·7단계 칸반이다. 헤더 탭으로 오간다. 데스크톱은 로고 옆 탭, 모바일(767px 이하)은 헤더 아래 전체 폭 탭 줄이며 계정 설정·로그아웃은 아이콘만 보인다(접근성 이름 유지).
- 지원 보드 탭 옆 숫자는 전체 지원 수다. 처음 조회가 끝나기 전에는 0으로 보이지 않도록 숨긴다.
- 지원 내역 조회는 `useApplicationsLoader`를 두 페이지가 함께 쓴다. 페이지에 들어올 때마다 다시 조회하되, 이미 조회한 세션이면 이전 목록을 바로 보여주고 뒤에서 갱신한다. 탭을 옮길 때마다 스켈레톤이 깜빡이지 않게 하려는 선택이며, 비용은 페이지 이동당 조회 1회다. 한국 날짜가 바뀐 뒤 화면으로 돌아오면 다시 조회해 마감 자동 탈락을 반영한다.
- 익스텐션의 `?import=1` 자동 가져오기, 가져오기 버튼, 결과 알림은 홈에 둔다. 익스텐션이 여는 주소(`/?import=1`)는 바뀌지 않는다.
- 1줄: 전체 지원 수·전형 현황 카드(7/12)와 지원 기록 업데이트 카드(5/12). 태블릿·모바일은 세로로 쌓는다.
  - 전형 현황 막대·범례는 칸반 컬럼과 같은 상태 토큰을 쓴다. 면접예정·면접완료는 같은 색이라 "면접" 하나로 묶는다. 색만으로 구분하지 않도록 범례에 이름·건수를 함께 쓰고, 막대에는 전체 건수를 읽는 접근성 이름을 둔다.
  - 지원 기록 업데이트는 익스텐션과 같은 platform 토큰(배경/글자)으로 사람인·잡코리아·원티드를 표시하고, 각 사이트의 지원현황 페이지를 새 탭으로 연다. 주소는 익스텐션 팝업 바로가기와 같다.
- 대표 숫자는 새 `display`(48/56) 타이포 토큰, 보조 숫자는 `heading-xl`을 쓴다. 아이콘 `download`, `arrow-right`를 추가했다.

### #147 검증

- `npm test`, eslint, UI 규칙 검사, `tsc --noEmit`, `npm run build` 통과.
- 프로덕션 빌드(:3100)에서 `scripts/verify-release-browser.mjs` 7개, `scripts/verify-auth-loading-seo.mjs` 4개 항목 통과. 릴리즈 스크립트는 카드 편집·계정 전환 확인을 지원 보드에서 하도록 바꿨고(계정 전환 후에는 헤더 탭으로 이동해 스토어 상태를 그대로 확인), SEO 스크립트에 `/board`의 noindex·사이트맵 제외를 추가했다.
- 예시 데이터 48건과 빈 계정으로 홈 1440/768/390px, 지원 보드 1440/390px를 확인했다. 가로 넘침과 브라우저 예외 없음.
- 실제 익스텐션 설치 상태의 가져오기와 `scripts/verify-history-browser.mjs`(익스텐션 빌드 필요)는 이번에 실행하지 않았다. 홈에 같은 이름의 "익스텐션에서 가져오기" 버튼과 결과 알림이 있어 스크립트 수정은 필요 없다.
