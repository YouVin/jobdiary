## 상세 설명 (Detailed description)

```
📝 지원현황, 여기저기 흩어져서 놓치고 있지 않나요?

취준일기 익스텐션은 사람인·잡코리아·원티드에 지원한 내역을 각 사이트의
지원현황 페이지에서 버튼 한 번으로 모아, 취준일기 웹앱에서 한눈에 관리할
수 있게 도와줍니다.

✅ 주요 기능

- 사람인 / 잡코리아 / 원티드 지원현황 수집 — 지원현황 페이지에서 버튼
  하나로 회사명, 공고명, 지원일, 상태를 한 번에 가져와요
- 여러 페이지 자동 수집 — 여러 페이지의 지원 내역을 순서대로 모아요.
  일부 페이지를 불러오지 못하면 안내 메시지를 확인하고 다시 시도해 주세요
- 상태 자동 정리 — 지원완료 / 불합격 / 지원취소 등 사이트마다 다른
  표기를 통일된 형식으로 정리해요
- 전체 복사 — 3개 사이트에서 모은 지원 내역을 표 형태로 클립보드에
  복사해 엑셀, 노션, 구글시트 등에 바로 붙여넣을 수 있어요
- 취준일기 웹앱으로 한 번에 가져오기 — 버튼 한 번으로 취준일기 웹앱에
  수집한 내역을 전달해요

🔒 개인정보는 이렇게 다뤄요

- 로그인 정보(아이디, 비밀번호, 인증 토큰)는 절대 수집하지 않아요
- 버튼을 눌렀을 때 지원현황 내용을 읽어요. 사람인은 같은 계정의 모바일
  지원현황도 요청해, 일치하는 지원 건의 연도 포함 마감일을 보충해요
- 잡코리아는 지원한 공개 공고의 마감일 정보를 교차 확인해 날짜를 보충해요.
  상시채용과 확인할 수 없는 날짜는 생략하며 조회 실패 시에도 지원내역은 저장돼요
- 수집한 정보는 브라우저 로컬 저장소에만 저장되고, 개발자나 제3자
  서버로 자동 전송되지 않아요
- 자세한 내용은 개인정보처리방침을 확인해 주세요: https://youvin.github.io/jobdiary-extension/privacy/

📌 이렇게 사용하세요

1. 사람인 / 잡코리아 / 원티드의 지원현황 페이지로 이동해요
2. 익스텐션 아이콘을 클릭하고 "지원내역 수집하기"를 눌러요
3. 다른 사이트에서도 같은 방식으로 반복해요
4. "취준일기 열기"를 눌러 모은 내역을 취준일기 웹앱으로 가져와요

취준일기와 함께 취업 준비 과정을 더 체계적으로 관리해 보세요.

설치 및 사용 안내: https://youvin.github.io/jobdiary-extension/
```

## 1.0.3 업데이트 안내

- 저장 내역을 불러오는 중인 상태와 조회 실패를 구분하고 다시 불러오기를 제공합니다.
- 팝업이 열려 있는 동안 저장 내역 변경을 반영합니다.
- 초기화 실패 안내와 키보드 포커스, 스크린리더 상태 안내를 개선했습니다.
- 원티드 페이지 전환 시 실제 지원 목록 갱신을 함께 확인합니다.

스크린샷은 `docs/store-screenshots/`의 기존 자료와 새 버전의 표시 문구가 일치하는지
실제 Chrome에서 확인한 뒤 업로드합니다. 공개 소개 페이지 변경은 GitHub Pages 배포 후 반영됩니다.

## 개발 중인 마감일 기능 (#63, 출시 전)

위 설명의 사람인·잡코리아 마감일 보충 안내는 개발 중 변경안이다. 아직 웹스토어에
반영하지 않았다. 실제 로그인된 PC Chrome에서 요청이 성공하는지 확인하고
다음 출시 버전을 정한 뒤 설명과 개인정보처리방침을 함께 공개한다.
모바일 첫 응답에서 정확한 날짜를 확인한 지원만 보충하며, 모든 지원의 마감일이나
마감된 공고의 과거 날짜를 수집한다고 안내하지 않는다.
